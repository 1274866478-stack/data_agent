# 任务管理

本目录用于跟踪 Data Agent V4 项目的开发任务和经验教训。

## 文件说明

### todo.md
当前待办任务列表，格式：
```markdown
## 待办任务
- [ ] 任务描述 (#issue编号)
- [ ] 另一个任务

## 进行中
- [ ] 正在进行的任务

## 已完成
- [x] 完成的任务
```

### lessons.md
经验教训总结，每次被纠正后记录：
```markdown
### [YYYY-MM-DD] 问题描述
- **场景**: 发生时的场景
- **错误做法**: 原本的错误做法
- **正确做法**: 纠正后的正确做法
- **提取规则**: 可复用的规则
```

## 使用原则

1. 开始任务前，先在 todo.md 中记录
2. 任务完成后，勾选对应项
3. 被纠正时，立即更新 lessons.md
